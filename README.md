# Subho's Computer Institute Website

Official website of Subho's Computer Institute, Barrackpore, Kolkata.

## Features
- ICSE (Class 4–10) Computer Coaching
- ISC & CBSE (Class 11–12) Computer Science
- Python Programming Course
- Campus Gallery
- Contact Form (Web3Forms API)
- SEO Optimized using react-helmet-async

## Tech Stack
- React.js
- React Helmet Async
- CSS3
- Web3Forms API

## Installation

```bash
npm install
npm run dev
